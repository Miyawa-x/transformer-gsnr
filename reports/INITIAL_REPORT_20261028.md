# 视觉 Transformer + GSNR：第一轮短报

**能接，而且梯度和优化器的正确性测试已经通过。现在还不能说它比普通训练更好。**

已经建好独立仓库，写了小型 ViT、分类与蒸馏入口。GSNR 分别测注意力、MLP、LayerNorm、分类头，并据此分配动量。学生任务仍是 100 类；每 10 个 epoch 记录 GSNR、下降速度、信号和噪声。

已完成的验证包括：三路蒸馏反向传播、特征通道对齐、相同动量时与普通 SGD 的更新一致、校准不改变模型/随机状态、动量缓冲器连续保存，以及断点恢复后更新一致。准确测试数量与耗时见 unit-tests.xml。另一个信息干预实验原来未运行的 14 项测试，也已经在新建的独立 CPU 测试环境里通过。

还有一次完全冻结参数的合成测量：微型 ViT 上计算了 52 个层/梯度流统计单元（包含全局项和未激活项），模型状态隔离检查通过，没有执行训练更新。这只说明测量链条能跑，不是自然图像实验结果。

目前最值得注意的三点：

1. **Transformer 没有原理障碍。** GSNR 处理的是梯度，注意力层也有梯度。LayerNorm 不依赖整批图片的均值，做固定参数比较更直接；但 patch 之间并不独立，不能拿 patch 数冒充样本量。
2. **GSNR 高不代表知识更多，也不保证蒸馏更好。** 分类头、attention、MLP 的曲线可以不同。接下来要同时看方向是否有利于分类，以及持续信号来自哪条梯度流。
3. **动量收益需要拆开解释。** 相同输入 GSNR=1 的一组合成梯度，仅改变排列顺序，μ=0.9 时缓冲器 GSNR 分别约为 361 和 1.42；这是合成反例，不是 ViT 训练结果。它说明光靠一个静态 GSNR 数字，不能决定动量去噪表现。高动量还会放大平均更新，后续必须排除步长混杂。

下一步是服务器上的短跑，先固定动量与自适应动量对照，再加入通过精度验收的 ViT 教师。目前 GPU/平台连接仍未恢复，本仓库没有正式训练、没有准确率结果，也尚未取得新的 GPU 分配。

代码不会悄悄把 AdamW 的 beta1 改成动态值。首版沿用 DeepKD 的 Heavy-Ball 公式，AdamW 另作对照。是否值得作为扩刊方向，要看同样模型/数据/训练预算下，收益是否可重复、成本是否合理，以及 GSNR、时间相关性和特征对齐之间是否有一致证据。
